The packaged worker is built from the pinned HoppouAI/Breeze-TTS-2.cpp source
revision recorded in build-info.json. Its Apache-2.0 license is included as
Breeze-TTS-2.cpp-LICENSE.txt.

The worker includes ggml at the pinned revision recorded in build-info.json.
Its MIT license is included as ggml-LICENSE.txt.

The worker uses cpp-httplib. Its full MIT license and copyright notice are
included as httplib-MIT.txt.

The native build disables the optional MP3/Shine target, so Shine's LGPL
library is not linked into this package. Vulkan remains a runtime dependency
of the host system and is not redistributed here.

Model GGUF files are separate runtime assets. This wheel contains no model
weights and no downloader or cache manager.
